# Security Policy

## Supported Versions

Only the latest `main` branch receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The CampusConnect team takes the security of intra-college student communications, academic credentials, and privacy very seriously.

If you believe you have found a security vulnerability (such as email domain bypass, unauthorized profile data access, or RLS misconfiguration):

1. **Do not disclose the issue publicly.** Do not post it in GitHub issues, batch channels, or campus forums.
2. Email the maintainers directly at `security@campusconnect.local` or contact your college student IT administrator.
3. Include the following details:
   - Type of issue (e.g. Broken Access Control, SQL/RLS injection, XSS)
   - Step-by-step reproduction instructions or a proof-of-concept
   - Impact assessment
4. We will acknowledge receipt within 48 hours and work with you on a patch prior to public disclosure.
